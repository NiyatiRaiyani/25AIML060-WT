## Aim
To integrate the StudentHub modules into one deployable portal and verify navigation, responsiveness, authentication, database operations, security, AJAX/API functionality and documentation.

## Modules integrated
1. Public home and events pages.
2. Student registration and login/logout.
3. Student dashboard and profile.
4. Admin dashboard and role-based access.
5. Student status management with search.
6. Event management CRUD (create, list and delete).
7. PHP JSON API for event listing.
8. Audit logging and shared responsive layout.

## Technologies
HTML5, CSS3, Bootstrap 5, JavaScript, PHP, PDO, MySQL, Git, GitHub and XAMPP.

## Security measures
Password hashing, prepared statements, server-side validation, output escaping, CSRF token validation, session ID regeneration, inactivity timeout and role checks.

## Deployment
The application is designed to run locally using Apache and MySQL through XAMPP. Optional Apache virtual-host instructions are provided in README.md. Vercel does not natively run this PHP/MySQL backend; a separate static frontend preview or PHP-compatible hosting is required.
